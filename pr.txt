5.  Code Examples
JavaScript (fetch)
const BASE = 'https://2u736o5k8k.execute-api.us-east-1.amazonaws.com/prod';

async function getStabilityScore(userData) {
  const res = await fetch(`${BASE}/api/stability`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(userData)
  });

  if (!res.ok) throw new Error(`API error: ${res.status}`);

  const data = await res.json();
  return {
    score:   data.routine_stability_index.overall_score,  // e.g. 78.5
    label:   data.routine_stability_index.label,           // e.g. 'Good'
    alerts:  data.irregularity_alerts,
    recs:    data.recommendations
  };
}

6.  Important Rules
Time format
•	Always use 24-hour HH:MM format — '23:30', '07:00', '00:15'
•	Do NOT include seconds — '07:00:00' will fail, use '07:00'
•	Cross-midnight sleep handled automatically e.g. sleep '23:30' wake '07:00'
•	Invalid times return score: 0 with a helpful alert, not a crash

Minimum data required
•	sleep_times and wake_times — at least 2 entries each
•	meals — at least 1 day of data (any of breakfast/lunch/dinner)
•	exercise — frequency_per_week and duration_minutes required, types is optional

CORS
•	Fully open — Access-Control-Allow-Origin: *
•	Call directly from any frontend, no proxy needed
